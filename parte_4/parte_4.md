1. Explica la diferencia entre Git y GitHub.

GitHub es una pagina que nos permite tener proyectos guardados en la nube y Git es lo que nos permite subir nuestros archivos a GitHub

2. Explica para qué sirve .gitignore.

Sirve para ingresar archios que no queremos que se muetren en GitHub.

3. Explica por qué .venv no debe almacenarse normalmente en GitHub.

Porque esto causaria problemas al subri los archivos a la nube.

4. Explica para qué sirve requirements.txt.

ESte sirve para que las personas que hagan un fork a nuestro proyecto sepan cuales son las librerias que deben instalar antes para que el programa funcione de manera correcta.

5. Explica la diferencia entre Stage, Commit y Push.

Stage solo es el estado en el que se encuentran nuestros archivo ya sea que esten listos para poder subirlos o no, commit solo los sube a la nube antes de que aparescan en el GitHub y el push sube todos los commits realizados para que aparescan en GitHub.

6. Explica por qué un repositorio puede tener varios commits antes de realizar un push.

Porque se estan subiendo como si fueran carpetas separadas cada una con un nombre diferente y archivos diferentes en su interior asi al hacer el push es como si solo se incorporaran esas carpetas al proyecto.
